# Моделі бізнес-процесів продукту «ФінКит» (Спринт 1)

У цьому каталозі розміщено моделі ключових бізнес-процесів онлайн-банкінгу «ФінКит», розроблені в межах Спринта 1 «Продукт і вимоги».

---

## 1. Інструмент і нотація

* **Нотація:** BPMN 2.0 (Business Process Model and Notation).
* **Інструмент моделювання:** [diagrams.net](https://app.diagrams.net/) (draw.io).
* **Версія середовища:** Web / Desktop Application.
* **Бібліотека фігур:** Стандартна бібліотека `BPMN 2.0` (розділ *More Shapes* -> *Business* -> *BPMN 2.0*).

---

## 2. Структура каталогу

* `01_money_transfer.drawio` — вихідний файл першої моделі бізнес-процесу («Переказ коштів»).
* `01_money_transfer.pdf` (або `.png`) — графічний експорт першої моделі для перегляду та звіту.
* `02_account_opening.drawio` — вихідний файл другої моделі бізнес-процесу («Відкриття рахунку»).
* `02_account_opening.pdf` (або `.png`) — графічний експорт другої моделі для перегляду та звіту.
* `review.md` — протокол внутрішнього рецензування моделей Тест-аналітиком за 10 пунктами чек-листа.
* `README.md` — опис інструментарію та інструкція з перегляду (цей документ).

---

## 3. Інструкція щодо перегляду та редагування моделей

### Варіант А: Перегляд експортованих копій (рекомендовано для швидкої перевірки)
Для швидкого ознайомлення відкрийте відповідні файли `.pdf` або `.png` безпосередньо у вебінтерфейсі GitHub або будь-якому переглядачі зображень/документів.

### Варіант Б: Відкриття вихідних файлів (`.drawio`) у diagrams.net
1. Перейдіть у вебверсію редактора: [https://app.diagrams.net/](https://app.diagrams.net/).
2. У стартовому вікні або меню оберіть: **File** (`Файл`) -> **Open from** (`Відкрити з`) -> **Device** (`Пристрій`).
3. Виберіть файл із розширенням `.drawio` з цієї папки.
4. Для коректного відображення та редагування переконайтеся, що в лівій панелі активовано фігури BPMN:
   * Натисніть **More Shapes** (`Більше фігур`) у лівому нижньому кутку;
   * У розділі **Business** встановіть позначку біля **BPMN 2.0**;
   * Натисніть **Apply** (`Застосувати`).
