### Непокриті або частково покриті вимоги
*   **Вимоги BL (BL-10...BL-30, BL-50...BL-80):** Покрито частково. Через інтерфейс ручними тест-кейсами перевіряються лише бізнес-правила BL-30 та BL-40. Решта логіки перенесена на автоматизовані юніт-тести у Спринті 4.
*   **Нефункціональні вимоги NFR (P-10, S-10 тощо):** Не покрито. Причина: нефункціональні вимоги (продуктивність, безпека) перевіряються оглядом або спеціалізованими інструментами поза межами ручного функціонального тестування поточного спринта.
